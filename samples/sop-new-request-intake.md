# SOP: Handling a New Request (Demonstration Project)

**Purpose:** Make sure every incoming request is logged, prioritized, and followed up until closed.
**Scope:** Requests received by email or chat.
**Owner:** Administrative Support | **Version:** 1.0 (sample)

## Steps
1. **Acknowledge.** Reply within the agreed response time and confirm what was asked.
2. **Log.** Add a row to the tracker: ID, requester, date received, summary.
3. **Prioritize.** Mark High, Medium, or Low using the priority guide below.
4. **Assign a due date.** Confirm with the requester if the date is unclear.
5. **Complete the task.** Follow the relevant procedure and keep notes.
6. **Check.** Review the output for accuracy and completeness.
7. **Update.** Tell the requester what was done and record the outcome.
8. **Close.** Set status to Done and file related documents.

## Priority guide
- High: blocks other work or has a fixed deadline. Target: same day.
- Medium: needed this week. Target: 3 working days.
- Low: routine or no deadline. Target: 5 working days.

## Common problems
- Missing details: ask one clear question, set status to Waiting, record the follow-up date.
- No reply after 2 days: send one reminder, then note it in the tracker.
